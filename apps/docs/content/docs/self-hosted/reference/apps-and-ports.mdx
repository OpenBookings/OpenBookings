## Shared packages

| Package | What it holds |
| --- | --- |
| `@openbookings/db` | The Postgres pool, Drizzle schema, migrations, booking lifecycle and the test harness |
| `@openbookings/auth` | Better Auth for both portals: magic links, passkeys, two-factor, social sign-in |
| `@openbookings/authz` | Tenant isolation: who may see or change which organisation, property, room or rate |
| `@openbookings/pricing` | Rates, availability, cancellation policy and tourist tax maths |
| `@openbookings/stripe` | Stripe Connect accounts, payments and the commission fee |
| `@openbookings/billing` | Commission ledger, invoices, VAT, ICP and DAC7 reporting, readiness |
| `@openbookings/mailing` | Email client and templates |
| `@openbookings/messaging` | Guest-host messaging, realtime tokens and retention |
| `@openbookings/support` | Support tickets shared by the host dashboard and the support bot |
| `@openbookings/demo` | Demo hotels generated in testing mode |
| `@openbookings/mode` | Testing-mode detection and its safety checks |
| `@openbookings/cache`, `images`, `maps`, `analytics`, `config` | Supporting code |
| `@openbookings/testing` | The local test database: schema snapshot, seed data and setup script |
