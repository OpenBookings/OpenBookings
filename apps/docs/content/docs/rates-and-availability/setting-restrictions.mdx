*Last updated: 10 September 2026*

## Overview

Restrictions let you stop a specific rate plan from selling, or attach conditions a guest's stay must meet.

## How to set a restriction

1. Select **Edit restrictions** on the toolbar. 
2. Choose the **Rate plan**.
3. Set the **From** and **To** dates.
4. Tick **Close this rate plan**, and/or fill in **Minimum stay**, **Maximum stay**, **Closed to arrival**, **Closed to departure**.
5. Add a **Note** explaining why. It is shown to whoever opens the cell later.
6. Select **Apply to range**.

You have to set at least one rule or tick the closure — an empty form is rejected. A maximum stay shorter than the minimum is also rejected.

## How to reopen closed dates

1. Select the red **Closed** bar in the grid.
2. Select **Reopen these dates**.
3. Check the date range, then select **Reopen dates**.

<Callout type="info">
  Closing a date performs a soft delete behind the scenes. This preserves the history of who closed the date and when, which you see in the panel when selecting a closed bar.
</Callout>

## Limitations and warnings

<Callout type="warn">
  Reopening lifts closures only. Any stay rules over the same dates stay in place, and the plan may still not sell the way you expect.
</Callout>

- Restrictions apply immediately and affect what guests can book. There is no preview and no undo. 
- Restrictions cannot be edited. To change one, set a new rule over the same dates.
- There is no button that clears stay rules — only closures can be lifted.
- Restrictions only affect one rate plan. To take a room type off sale entirely, [edit availability](/docs/rates-and-availability/editing-availability).
