## Photos

| | |
| --- | --- |
| Accepted formats, room photos | JPEG, PNG, WebP |
| Accepted formats, property photos during setup | PNG, JPG, WEBP |
| Maximum size | 10 MB per file |
| Number of files | No stated limit |

Photos cannot be deleted, reordered, or set as the main image once uploaded.

| | |

| Editing | Always across a date range, never a single cell in place |

## Amounts

Reservation amounts are shown in euros. Rate plan prices use the currency set on the plan.

## How long messages are kept

Conversations with no activity for **12 months** are cleared automatically. The message text is replaced with a note saying the retention period expired, and the sender is no longer recorded.

<Callout type="warn">
  This cannot be undone. If you need a record of an exchange beyond a year, save it elsewhere before the year is up.
</Callout>

## Contact details in messages

Messages that appear to contain a phone number, email address or messaging-app handle are **flagged but still delivered**. The sender sees a warning, and the message keeps a **Flagged** label permanently. See [Messages](/docs/bookings/messages).

## What is recorded when you sign the Partner Agreement

Your IP address is captured at the moment of signing and stored as part of the legally binding record. The signing window tells you this before you confirm. Once signed, the legal detail fields are locked.

## Access

There are no separate roles. Everyone signing in to your property's business account can take the same actions, including changing rates and taking rooms off sale. Each account sees only the property it owns.
