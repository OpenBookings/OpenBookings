## Overview

**Reservations** is the full list of bookings for your property. 

## How to find a booking

1. Go to **Bookings → Reservations**.
2. Select the button at the top left to switch between the four lists: **Upcoming**, **Check-ins**, **Check-outs** and **In-house**.
3. Scroll through the table to find the row you need.

Each list option shows its own count, so you see how busy a list is before opening it.

## How to search for a booking

Press **⌘K** (**Ctrl+K** on Windows) to open the command menu, and type a reservation number or guest name to jump straight to a booking from anywhere in the dashboard.

## Limitations and warnings

- There is no free-text search or filter on the Reservations screen itself beyond the four lists. Use the command menu to search.
- The reservations listed are sample data, not your property's real bookings.
