## Overview

This page covers setting and lifting rules on the [Rates & Availability](/docs/reference/rates-and-availability) grid. For what each rule does to a guest — and how closures differ from sold out — read [Restrictions and closures](/docs/explanation/restrictions-and-closures) first.

## What you can do here

- Close a rate plan for a range of dates
- Require a minimum number of nights, or cap the maximum
- Stop guests arriving or departing on particular dates
- See who set a rule and when
- Reopen dates you previously closed

## How to set a restriction

1. Select **Edit restrictions** on the toolbar. Selecting a cell first and using the **Edit restrictions** button in its panel fills in the plan and dates for you.
2. Choose the **Rate plan**. Each option is listed as room type and plan name.
3. Set the **From** and **To** dates.
4. Set whatever you need — tick **Close this rate plan**, and/or fill in **Minimum stay**, **Maximum stay**, **Closed to arrival**, **Closed to departure**.
5. Optionally add a **Note** explaining why. It is shown to whoever opens the cell later.
6. Select **Apply to range**.

You have to set at least one rule or tick the closure — an empty form is rejected. A maximum stay shorter than the minimum is also rejected.

## How to see what a rule does and who set it

1. Select the coloured bar in the grid.
2. The panel names the rule in plain language — for example *The rate plan is still bookable, but guests must book at least 3 nights to include these dates.*
3. It shows the exact date range the rule covers, who set it, when, and any note.

For a closure, the panel confirms that guests cannot book the plan even though rooms are available, and that it affects this plan only.

## How to reopen closed dates

1. Select the red **Closed** bar in the grid.
2. Select **Reopen these dates**.
3. Check the date range, then select **Reopen dates**.

<Callout type="warn">
  Reopening lifts closures only. Stay rules over the same dates stay in place, and the plan may still not sell the way you expect.
</Callout>

## What to do about "Sold out"

A grey striped **Sold out** bar is not a restriction — the room type has no rooms left, so every rate plan on it is unsellable. Reopening will not help. Select the bar and use **Fix availability**, which takes you to [Editing availability](/docs/how-to/editing-availability).

## Tips

- Always leave a note. Weeks later, it is the only thing that explains why a date was closed.
- Before a busy period, use **Show only with issues** in the Filter menu to catch dates still closed from last season.

## Limitations and warnings

<Callout type="warn">
  Restrictions apply immediately and affect what guests can book. There is no preview and no undo. Check the **From** and **To** dates before applying.
</Callout>

- Restrictions cannot be edited. To change one, set a new rule over the same dates.
- There is no button that clears minimum or maximum stay rules — only closures can be lifted with **Reopen these dates**.
- Restrictions only ever affect one rate plan. To take a room type off sale entirely, change its availability.
