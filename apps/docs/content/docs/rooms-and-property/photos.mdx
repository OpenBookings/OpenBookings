## Overview

While the main Rooms page is a placeholder, the photo upload screen for an individual room does work. 

## How to add room photos

1. Open the room images screen for the room via a direct link. 
2. Drop image files onto the dashed box, or select **browse** to pick them. 
3. Your chosen files are listed below the box. Select the cross beside any file to take it out of the list before uploading.
4. Select **Upload** to send them.
5. Each file shows its progress and joins the grid above once it has finished.

## Limitations and warnings

- You can only upload JPEG, PNG, and WebP files.
- The maximum file size is strictly 10 MB (10,485,760 bytes) per photo.
- Photos cannot be deleted once uploaded, and they cannot be reordered or set as the main image. Check a photo before you select Upload.
- Because the Rooms list is not available, the room images screen cannot be reached from the menu today.
