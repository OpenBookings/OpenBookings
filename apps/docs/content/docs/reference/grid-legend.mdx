A lookup for the [Rates & Availability](/docs/property/rates-and-availability) screen.

## Availability cells

| What you see | Meaning |
| --- | --- |
| Plain number | Rooms available. |
| Amber number | Two or fewer rooms left. |
| Red number | No rooms left to sell. |
| Small dot after the number | A manual availability override is in effect. |

## Rate plan cells

| What you see | Meaning |
| --- | --- |
| A price | The plan is open and bookable at that rate. |
| A price with `*` | The plan has a longer-stay discount this price does not include. |
| `—` | No rate resolved for this date. |
| Red bar, ban icon, **Closed** | You closed this rate plan. Affects this plan only. |
| Grey striped bar, **Sold out** | The room type has no rooms left. Affects every plan on it. |
| Amber bar, warning icon, **Restricted** | Bookable with conditions, named on the bar. |

Every state carries a colour, an icon and a word, and sold out is striped as well — so none of them depends on telling colours apart.

## Restriction bar labels

| Label | Meaning |
| --- | --- |
| **Min 3 nt** | Minimum stay of three nights. |
| **Max 5 nt** | Maximum stay of five nights. |
| **No arrival** | Closed to arrival. |
| **No departure** | Closed to departure. |

Several may appear on one bar, separated by dots.

## Rate plan row markers

| Marker | Meaning |
| --- | --- |
| Green dot | Every date in view is open. |
| Amber dot | Some dates are closed or restricted. |
| Red dot | No dates in view are bookable. |
| **NR** | Non-refundable rate plan. |

## Room type row

| What you see | Meaning |
| --- | --- |
| *2/4 plans open* | Collapsed summary — how many rate plans are selling on at least one date in view. |
| *8 units* | Expanded — the room type's total unit count. |
| **Available rooms** | The row showing the shared pool of rooms, once expanded. |

## Column tints

| Tint | Meaning |
| --- | --- |
| Highlight colour | Today. |
| Faint grey | Saturday or Sunday. |

## Keyboard shortcuts

The grid is a single stop when tabbing through the page. Once inside it:

| Key | Does |
| --- | --- |
| Arrow keys | Move one cell in any direction. |
| **Home** | Jump to the first date in view. |
| **End** | Jump to the last date in view. |
| **Page Up** | Jump to the first row. |
| **Page Down** | Jump to the last row. |
| **Enter** or **Space** | Open the details panel for the selected cell. |

Elsewhere in the dashboard, **⌘K** (**Ctrl+K** on Windows) opens the search and command menu from any screen.
