## Overview

This page covers working with rate plans on the [Rates & Availability](/docs/property/rates-and-availability) grid. For how a price is actually built up, read [Pricing](/docs/concepts/pricing) first.

Expand a room type in the grid to see its rate plan rows.

## What you can do here

- See each plan's price for every date
- See exactly which rules moved a price up or down
- Compare what a guest would pay for a longer stay
- Add a new rate plan to a room type

## Reading a rate plan row

The row starts with a coloured dot summarising the dates in view, then the plan's name. **NR** at the end of the row marks a non-refundable plan.

| Dot | Meaning |
| --- | --- |
| Green | Every date in view is open. |
| Amber | Some dates are closed or restricted. |
| Red | No dates in view are bookable. |

## How to see why a price is what it is

For a quick check, hover the price. A summary shows the plan name, the final price, the base rate (or the word *Override*), and each adjustment that fired with its amount — for example *−10%* or *+€15*.

For the full picture:

1. Select the price cell.
2. The panel opens on **Price breakdown**.
3. The top line is the base rate, or the rate override if one applies — in which case the panel names it and tells you the plan's normal base rate.
4. Below it, every adjustment on the plan is listed in the order it is applied. Ones that fired show their amount; ones that did not are dimmed and marked *not applied*.
5. The bottom line is the final price per night, labelled with the stay length it was worked out for.
6. **Rate plan** below the breakdown shows cancellation terms, minimum and maximum stay, and how many rooms are free.

## How to check the price for a longer stay

Change the stay length list on the toolbar to **Rates for 3 nights** or **Rates for 7 nights**. Prices recalculate for a booking of that length, and any longer-stay discount that qualifies is applied. This is how you answer "what would a week actually cost?" without doing the arithmetic yourself.

The panel tells you when this is worth doing — if a plan has a discount your current stay length does not qualify for, it says so.

## How to add a rate plan

1. Select **Add rate plan** on the toolbar.
2. Choose the **Room type** the plan belongs to.
3. Give it a **Name** guests will understand, such as *Non-refundable*.
4. Set the **Base rate**. The currency is shown on the field label.
5. Set **Minimum stay** and, if you want one, **Maximum stay**.
6. Tick or clear **Refundable**.
7. Optionally describe your **Cancellation policy**.
8. Select **Create rate plan**.

<Callout type="info">
  A new rate plan sells the room type's existing rooms. It does not add units to your property.
</Callout>

## Tips

- Give plans names a guest would understand — the name is doing the explaining.
- Use the hover summary to scan a whole week for odd prices, then open the panel on the one that looks wrong.

## Limitations and warnings

- Price adjustments can be seen here but not created or edited. The panel is for understanding a price, not changing the rules behind it.
- The same applies to rate overrides: if one is in effect the panel tells you, but there is no way to set or remove one here.
- Once created, a plan's name, base rate, refundability and stay limits cannot be changed, and a plan cannot be deleted.
