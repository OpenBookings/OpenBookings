## Overview

**Rooms** under the Property section is where your room types will be managed. The main page is not built yet — opening it shows a **Coming soon** message — but photo upload for an individual room does work.

Room types themselves are what the [Rates & Availability](/docs/property/rates-and-availability) grid is built on: each room type has a number of units and one or more rate plans.

## What you can do here

- See the photos already uploaded to a room
- Add more photos to that room

## How to add room photos

1. Open the room images screen for the room. Photos already on the room appear in a grid at the top.
2. Drop image files onto the dashed box, or select **browse** to pick them. JPEG, PNG and WebP files up to 10 MB each are accepted.
3. Your chosen files are listed below the box. Select the cross beside any file to take it out of the list before uploading.
4. Select **Upload** to send them.
5. Each file shows its progress — *queued*, a percentage, then *done* — and joins the grid above once it has finished.
6. Use the arrow at the top left of the screen to go back to Rooms.

## Tips

- Photos are shown to guests, so upload the largest, best-lit version you have rather than a thumbnail.
- Nothing is uploaded until you select the **Upload** button, so you can queue several files and review the list first.

## Limitations and warnings

<Callout type="warn">
  The main Rooms page is not built, so there is currently no way to browse your rooms, add a room type, change a room's name, or set how many units it has from the dashboard.
</Callout>

<Callout type="warn">
  Photos cannot be deleted once uploaded, and they cannot be reordered or set as the main image. Check a photo before you upload it.
</Callout>
