---
title: Glossary
description: The terms the dashboard uses, defined in one place.
---

| Term | Meaning |
| --- | --- |
| **Availability** | How many rooms of a room type are free to sell on a date. See [Availability](/docs/concepts/availability). |
| **Availability override** | An explicit number that replaces the availability calculation entirely. Does not adjust as bookings arrive. |
| **Base rate** | The starting price for a rate plan, before adjustments. Shown in places as the BAR. |
| **BAR** | Best Available Rate — another name for the base rate. |
| **Blocked units** | Rooms held back from sale for maintenance or owner use. Subtracted from the availability calculation. |
| **Booked** | Units taken by confirmed and completed bookings. Maintained for you. |
| **Capacity override** | A different total room count for particular dates, feeding the availability calculation. |
| **Cell** | One square in the Rates & Availability grid — one room type or rate plan, on one date. |
| **Checked in** | Reservation status: the guest is on the property. |
| **Checked out** | Reservation status: the stay is finished. |
| **Closed** | A rate plan you have deliberately made unbookable for a date range. Affects that plan only. |
| **Closed to arrival** | A rule stopping guests checking in on a date. A stay may still run through it. |
| **Closed to departure** | A rule stopping guests checking out on a date. |
| **Confirmed** | Reservation status: booked and expected. |
| **Day of week** | A price adjustment firing on particular days, such as a weekend uplift. |
| **Early bird** | A price adjustment firing when a booking is made far enough before arrival. |
| **Extra guest** | A price adjustment firing when a booking exceeds the room's standard occupancy. |
| **Flagged** | A label on a guest message that appears to contain contact details. |
| **In-house** | A guest currently staying. On the Overview screen this card counts guests, not reservations. |
| **Last minute** | A price adjustment firing when arrival is close. |
| **Length of stay** | A price adjustment discounting longer bookings. |
| **Maximum stay** | A rule capping how long a stay covering these dates can be. |
| **Minimum stay** | A rule requiring at least that many nights for a stay covering these dates. |
| **Modifier** | Another name for a price adjustment. |
| **NR** | Marker on a rate plan row meaning non-refundable. |
| **Pending** | Reservation status: needs a decision, or not yet confirmed. |
| **Rate override** | A price replacing the base rate on particular dates. Adjustments still apply on top. |
| **Rate plan** | One way of selling a room type, with its own rate, terms and stay rules. |
| **Restricted** | A rate plan still bookable but with conditions attached. |
| **Room type** | A group of interchangeable rooms, with a number of units. Availability is counted here. |
| **Sold out** | A room type with no rooms left, making every rate plan on it unsellable. |
| **Stay length** | The number of nights the grid prices against — 1, 3 or 7. Changes which discounts apply. |
| **Units** | How many physical rooms a room type has. |
