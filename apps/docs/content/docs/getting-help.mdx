## Overview

Help is reached from the lower part of the sidebar. Four items sit there: **Notifications**, **What's New**, **Support** and **Documentation**.

## What you can do here

- Read recent activity on your property
- Read announcements about changes to the dashboard
- Open this documentation

## Notifications

Select **Notifications** to open a window listing recent activity across your property — new reservations, payouts, reviews — newest first. A dot appears beside the item in the sidebar when there is something you have not read; opening the window clears it.

If there is nothing waiting, it says *You're all caught up.*

## What's New

Select **What's New** for the latest changes to the dashboard, each with a date and short description. This also shows a dot for unread entries. It is the place to watch for features that are currently marked *Coming soon*.

## Support

**Support** in the sidebar opens a page that is not built yet — it shows a **Coming soon** message.

<Callout type="warn">
  There is no working support form, help centre search or contact channel in the dashboard yet. The **Search Help Center**, **Send Feedback** and **Contact Support** entries in the command menu do not do anything either.
</Callout>

## Documentation

**Documentation** opens this guide in a new tab. You can also reach it from anywhere at the same address.

## Tips

- The dot beside Notifications and What's New is remembered by the browser you are using, so opening them on your laptop will not clear the dot on a shared front-desk machine.

## Limitations and warnings

- Notifications are read-only — nothing there can be actioned or dismissed individually.
- The entries currently shown under Notifications and What's New are examples rather than live activity on your property.
