## Overview

**Rates & Availability** — shown as **R&A** in the sidebar — is the calendar grid where you control what you sell. Dates run across the top, room types run down the side, and every square tells you how many rooms are free or what a rate plan costs.

## How to expand a room type

The layout groups ways of selling under the shared pool of rooms.

**Collapsed**, a room type is a single row showing the number of rooms available on each date.

**Expanded**, the rows become:
- **Available rooms**, showing the shared pool free on each date.
- One row per rate plan, showing the price.

Select the arrow at the start of a room's row to expand or collapse it.

## How to move through dates

1. Use the arrows either side of **Today** to step back or forward by exactly the period you are viewing.
2. Select **Today** to jump back to the current date.
3. Use the date range list to switch between **Next 7 days**, **Next 14 days** and **Next 30 days**.

## How to focus on the rooms you care about

1. Select **Filter**.
2. Clear the tick beside any room type you want out of the way.
3. Optionally tick **Show only with issues** to see only rooms with something closed, restricted or sold out.
4. The **Filter** button shows how many filters are active.

To clear them, select the filter icon that appears next to the button. Filters stay on as you move between weeks.

## Limitations and warnings

<Callout type="warn">
  This screen is for large screens only. On a phone or narrow window, it shows *Open this on a desktop*. This prevents accidental taps closing rooms.
</Callout>

- You can only view 7, 14 or 30 day periods. Step forward with the arrows to plan further out.
- Selecting a cell shows information; it does not let you edit in place. All changes go through the toolbar buttons.
