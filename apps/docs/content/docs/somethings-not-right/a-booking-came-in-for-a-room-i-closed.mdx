## Overview

When you see a booking on a date you thought was unavailable, the cause is almost always how closures work across a shared pool of rooms.

## How to check rate plan closures

Closures apply to a single rate plan, not to the physical room. If you close the *Non-refundable* plan for Tuesday, the *Flexible* plan is still actively selling those rooms for Tuesday. 

1. Open **Rates & Availability**.
2. Expand the room type using the arrow.
3. Look at all the rate plans for that date. If any plan shows a price instead of a red **Closed** bar, a guest can book the room.

To close a room type entirely, use [Edit availability](/docs/rates-and-availability/editing-availability) to block units, which removes them across all rate plans at once.
