## Global shortcuts

- **⌘K** (Mac) or **Ctrl+K** (Windows) — Open the command menu to jump to a section or search for a reservation.

## Message shortcuts

- **Enter** — Send a message.
- **Shift+Enter** — Start a new line in a message without sending.
