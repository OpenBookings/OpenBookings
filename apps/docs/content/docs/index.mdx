## What is not built yet

OpenBookings is still growing. Several areas in the menu show a **Coming soon** message rather than working screens — Finance, Analytics, Reviews, Property details and Rooms are the main ones. Every page in this guide says plainly what works today and what does not, so you are never left guessing.
